## 进入 MVP 的建议门槛（请项目负责人确认或修改）
在法学冻结标签的**锁定测试集**上一次性评估：
- JSON 契约通过率 ≥ 95%，证据子串率 = 100%；
- 否定/引用切片误报率不高于基线；
- `review` 类召回 > 0 且显著高于“全部判 flag”的退化策略；
- 合并二分“需人工看”召回不低于基线。
未达门槛 → 缩小任务（例如只做“需人工看 + 证据定位”二分）或换方向，不用更大模型掩盖。
